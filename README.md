# SocialTask — واجهات MVP

مشروع React + Vite لواجهة سوق خدمات رقمية بثلاثة أدوار: العميل، المنفذ، والإدارة.

## مهم: لماذا قد تظهر شاشة بيضاء؟
هذا ملف مشروع React وليس صفحة HTML مستقلة. لا تفتح `index.html` مباشرة من مدير الملفات، ولا تفتح ملف ZIP كأنه موقع. يجب فك الضغط وتشغيله بخادم Vite أو نشره على استضافة تدعم React.

## التشغيل محلياً
1. ثبّت Node.js (الإصدار 18 أو أحدث) على الكمبيوتر.
2. فك ضغط الملف كاملاً.
3. افتح مجلد `SocialTask_App` في Terminal.
4. نفّذ:
   ```bash
   npm install
   npm run dev
   ```
5. افتح الرابط المحلي الذي يظهر في Terminal (عادةً `http://localhost:5173`).

إذا كنت تعمل من الهاتف فقط، ارفع المشروع إلى GitHub ثم انشره عبر Vercel أو Netlify؛ لا يكفي فتح `index.html` من الهاتف.

## ربط Supabase
1. أنشئ مشروع Supabase.
2. شغّل ملف `socialtask_schema.sql` داخل SQL Editor.
3. انسخ `.env.example` إلى `.env`.
4. ضع Project URL و anon public key في `.env`.
5. أنشئ مستخدم اختبار من Authentication.
6. عيّن دور الإدارة من SQL Editor فقط:
   ```sql
   update public.profiles
   set role = 'admin'
   where id = 'AUTH_USER_UUID';
   ```

## حدود النسخة الحالية — اقرأ قبل الإطلاق
- الواجهات والتنقل والنماذج تعمل كـ MVP تفاعلي، وتعرض بيانات تجريبية عند عدم الاتصال بقاعدة البيانات.
- لا تزال عمليات تحميل البيانات الحقيقية، إنشاء الطلبات، حجز الطلبات، رفع الملفات، اعتماد الدفع، تسوية المحفظة والسحب بحاجة إلى Edge Functions / server-side workflows وربطها بالكامل.
- زر اعتماد الدفع في الواجهة التجريبية يغيّر الحالة محلياً فقط. لا تستخدمه كإثبات دفع حقيقي.
- لا تُخزّن كلمات المرور أو مفاتيح Binance Pay في الواجهة.
- BaridiMob: العميل يرفع مرجع التحويل/الإيصال، والإدارة تتحقق من حسابها فعلياً قبل الاعتماد.
- Binance Pay: لا تفعّل استقبال أموال فعلياً قبل إعداد حساب تاجر مؤهل، والتحقق من المعاملة عبر واجهة رسمية من الخادم.
- لا تبيع متابعين أو إعجابات أو مشاهدات وهمية أو آلية. استخدم خدمات تسويق وصناعة محتوى وتفاعل أصيل متوافق مع شروط المنصات.
- لا تنشر المنصة للعامة قبل مراجعة سياسات RLS وإضافة عمليات خادمية آمنة للرصيد والعمولات.

## ملفات المشروع
- `src/App.jsx`: الشاشات والتفاعلات الأساسية.
- `src/styles.css`: التصميم الداكن والمتجاوب.
- `src/supabase.js`: إعداد عميل Supabase.
- `socialtask_schema.sql`: مخطط قاعدة البيانات وسياسات أولية.
